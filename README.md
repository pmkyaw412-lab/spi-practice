# SPI 弱点報告書

SPI（テストセンター／WEBテスティング）の弱点を、企業が受け取る報告書と同じ **7段階** で見える化し、型ごとに練習するサイト。1ファイルの静的ページで、記録はブラウザの localStorage に保存される。

**Live:** https://pmkyaw412-lab.github.io/spi-practice/

## できること

- **報告書** — 出題パターンごとの段階（1〜7）を、直近10問の正答率と解答時間から算出。段階3以下は赤で示し、「次にやること」を提案する。
- **練習** — 模擬（約20問、本番の順序と配分）、弱点（間違えた問題の解き直し、間隔をあけて再出題）、推論15問、言語20問、型を選んで練習。問題ごとに本番の制限時間バーが付く。
- **出題パターンと解き方** — 型ごとの「解き方」と「落とし穴」。
- **週間サイクル** — 1週間で一周する練習計画とチェックリスト。

右上の切り替えで **テストセンター** と **WEBテスティング（自宅受検）** の出題に合わせて内容が変わる。

| | テストセンター | WEBテスティング |
|---|---|---|
| 言語 | 二語の関係、語句の意味、語句の用法、並べ替え、空欄補充、長文 | 熟語の成り立ち、3文完成、並べ替え、空欄補充、長文 |
| 非言語 | 推論（順序、位置、対応、正誤、命題、うそつき、対戦、内訳）、図表、集合、場合の数、確率、損益、割合、料金、分割払い、速さ、仕事算 | 左に加えて **整数の推測**（数値入力）と **推論：アとイ**（情報の過不足を判定） |
| 電卓 | 使えない（メモ欄で計算） | 使える |

WEBモードには **WEB専用ドリル 12問**（整数の推測 6問 → 推論アとイ 6問）がある。

## 問題について

全379問はこのページのために作ったオリジナル。非言語の答えはプログラムで検算してある（アとイの推論は全ケースを列挙して「アだけ／イだけ／両方」で答えが1つに決まるかを確認）。

## ファイル

- `index.html` — サイト全体（HTML、CSS、JavaScript、問題データ）
- `.nojekyll` — GitHub Pages でそのまま配信するための空ファイル
